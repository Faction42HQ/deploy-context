# Authoritative Sources

Use in this priority order. This repo is a stable summary; **volatile specifics live in the docs.**

1. **Live product docs — https://docs.deploy.finance** (canonical).
   Fetch the specific page for exact **fees, minimums, supported markets, and mechanics**.
   Do not quote these from memory.
2. **This repository** — stable identity, products, mechanics, terminology, voice.
3. **Team's living product/changelog** (internal) — for what has shipped recently.

## Docs map (docs.deploy.finance)
- **Getting Started** — basics, wallet management, the thesis.
- **Products** — agent overviews, how-to-choose, fees.
- **Guides** — quick-start, how-to, troubleshooting, safety, lifecycle, MCP integration.
- **Resources** — alternatives, legal.
- **FAQ** and **Risks**.

## Rule
If a product statement is not confirmed by (1) or (2), do not publish it — escalate for review.
