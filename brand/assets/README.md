# Brand assets

Exported from the Deploy Agents Figma brand guidelines:
https://www.figma.com/design/Gz3hxiXboj6eDSZNcBJRm1/Deploy-Agents?node-id=723-1817

Usage rules (clear space, minimum sizes, color pairings, imagery, misuse) are in
[../design-system.md](../design-system.md). Use these files as-is — never redraw or recolor logos.

## logos/
| File | What | Use on |
|------|------|--------|
| `symbol.svg` | Symbol, Blue Glow `#474DEF` (mark is a transparent cut-out) | Any approved background |
| `lockup-on-light.svg` | Symbol + wordmark, black wordmark | White / light gray |
| `lockup-on-dark.svg` | Symbol + wordmark, white wordmark | Soft Black |
| `app-icon-blue.svg` | App icon, 241×241, Blue Glow container | Dark / light |
| `app-icon-white.svg` | App icon, 241×241, white container | Dark / Blue Glow |

## backgrounds/
Flattened PNG renders of the `bg` frames used in social, X header and slide templates
(soft blue-violet gradient fields). `bg-x-header-*` are the lighter header fields;
`bg-wide|tall|square|large|gradient-*` are the template backgrounds. `orbit-frame.png` is the
concentric-orbit illustration frame.

## textures/
Original source images (PNG/JPG, de-duplicated) used as fills in the templates: blurred blue
orbs/spheres and soft-lit forms. Per the design system, imagery stays inside the brand ramps.

## illustrations/
Vector illustrations: `orbit.svg` (concentric ellipses) and `shape-*.svg` (supporting shapes).
